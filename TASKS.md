### TASK-01. Разметить аллергены вручную и исправить правила

- **Проблема:** разметка автоматическая, а правила пропускают обычные продукты. Без тегов остались `flour` (516 вхождений), `all purpose flour` (242), `hamburger bun` (323), `yellow cake mix` (245), `pizza dough` (134), `pesto` (121), `pie shell` (84), `refrigerated crescent roll` (83), `nut` (78), `panko` (62), `gnocchi` (59), `alfredo sauce` (58). Для пользователя с целиакией рецепт с `flour` проходит фильтр.
- **Причина в правилах:** нет общего правила для муки; срабатывает только первое совпадение, поэтому `egg noodle` получает `eggs`, но не `wheat`. Поиск идёт по подстроке, отсюда ложные теги: `eggplant` → `eggs`, `fryer chicken` → `gluten` через `rye`, `cream of tartar` → `dairy`.
- **Подтверждено:** в `allergens_review.csv` 402 раза `yes` и 1182 пустых значения, теги на 100 % совпадают с правилами, то есть правок человека нет. Поиск по ключевым словам нашёл 86 неразмеченных позиций (7718 вхождений). Это кандидаты: часть из них, например `rice flour`, тегов не требует.
- **Сделать:** собрать все подходящие теги вместо первого, сравнивать по границам слов, дополнить правила, затем проверить вручную все 1584 позиции.
- **Важно:** `cmd_allergens` не перезаписывает существующий файл, поэтому исправленные правила не дойдут до базы, пока файл не удалён. `load` пропускает только строки с `no`, пустой `confirmed` загружается как подтверждённый.
- **Готово, когда:** в файле отмечена ручная проверка, а `load` отказывается работать без неё; есть тесты правил на `flour`, `egg noodle`, `eggplant`.
- **Файлы:** `tools/ingest/ingest/allergens.py`, `tools/ingest/ingest/__main__.py`, тесты ingest (сейчас их нет).

### TASK-02. Не терять строки ингредиентов с аллергенами при загрузке

- **Проблема:** неразрешённая строка молча выпадает при `load`, связи с рецептом нет, и `NOT EXISTS` её не видит. У 2712 рецептов (4,37 %) выпала строка с аллергеном: `dairy` 1083, `gluten` 505, `wheat` 490, `fish` 294, `shellfish` 275, `tree_nuts` 135, `peanuts` 62, остальные меньше. Например, `crab` (19 вхождений) и `feta` (18) не набрали порог `MIN_CANONICAL_FREQ = 20`. Критерий «менее 5 %» при этом выполнен, поэтому проблема его проверкой не ловится.
- **Побочный эффект:** у 14 062 рецептов (22,6 %) выпала хотя бы одна строка, поэтому их `missing_count` занижен.
- **Подтверждено:** прогоном по корпусу; в dev-базе не проверялось.
- **Сделать:** имя, которому правила ставят аллерген, всегда становится канонической позицией, независимо от частоты. Считать отдельную метрику «рецепты с потерянным аллергеном» и падать, если она не ноль.
- **Решить до кода:** что делать с рецептами, где остались прочие неразрешённые строки: показывать как сейчас или скрывать из поиска. Скрытие безопаснее, но уменьшит выдачу примерно на пятую часть.
- **Готово, когда:** метрика равна нулю на полном корпусе; для новой метрики есть тест.
- **Файлы:** `tools/ingest/ingest/__main__.py`, `tools/ingest/ingest/db.py`, `tools/ingest/README.md`.

### TASK-05. Решить, что делать с именами вне каталога

- **Проблема:** имя, которого нет в каталоге, не проверяется на аллергены и попадает только в `warnings` (`internal/cook/validator.go:192`). План требует отправлять такие имена в `missing[]`. Если, например, `peanut sauce` не разрешится через каталог, ответ пройдёт валидацию у пользователя с аллергией на арахис. Кроме того, `missing[]` строится только из имён, названных моделью: продукт исходного рецепта, о котором модель умолчала, в нём не появится.
- **Подтверждено:** чтением кода; текущее поведение закреплено `TestValidateReportsIngredientsAbsentFromTheCatalog`.
- **Решить до кода (§12):** при непустом запрете отклонять ответ с неразрешённым именем или прогонять такие имена через правила аллергенов. Отказ безопаснее, но повысит долю неадаптированных fallback, долю надо оценить на прогонах.
- **Сделать:** выбранный вариант; неразрешённые имена показывать в `missing[]` или явно объяснить в ответе; добавить строки исходного рецепта, которых нет у пользователя.
- **Готово, когда:** новые тесты описывают оба случая; при изменении поля `missing_ingredients` обновлён `api/openapi.yaml`.
- **Файлы:** `internal/cook/validator.go`, `internal/cook/validator_test.go`, возможно `internal/cook/worker.go`.
